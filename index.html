Visão geral

O go-ide é um editor de texto desktop construído com Fyne, focado em desenvolvimento Go. Combina um editor com TextGrid, tema escuro inspirado em One Dark Pro, terminal PTY embutido e comunicação JSON-RPC com o gopls.

Explorador de arquivos

Navegue pela árvore do projeto e abra arquivos com um clique.

Editor com numeração

TextGrid com gutter de linhas, caret piscante e clique para posicionar o cursor.

Realce de sintaxe Go

Funções, tipos, packages, keywords, strings, comentários e números coloridos.

Rainbow brackets

Parênteses, colchetes e chaves coloridos por nível de aninhamento.

Autocomplete gopls

Sugestões inline com filtro local, snippets e debounce inteligente.

Navegação LSP

Definição, referências, rename, hover, signature help e diagnósticos.

Terminal integrado

Shell interativo com execução de go run via F5.

Persistência de estado

Reabre a última pasta e mantém lista de pastas recentes.

Instalação e requisitos

Go 1.26+, Fyne e gopls instalados no sistema.

Compilar a partir do código

# clonar e compilar
git clone https://github.com/bapadua/go-ide.git
cd go-ide
go build -o go-ide .
./go-ide

Dependências externas

  • Go — 1.26 ou superior
  • gopls — go install golang.org/x/tools/gopls@latest
  • goimports — usado na formatação (Shift+Alt+F)
  • Linux com suporte a PTY para o terminal
  • Abra uma pasta de projeto para o gopls funcionar
  • Configure o GOROOT em Arquivo → Propriedades se necessário

Configuração persistente

Estado salvo em ~/.config/go-ide/state.json:

{
  "last_folder": "/caminho/para/projeto",
  "recent_folders": [
    "/caminho/para/projeto",
    "/outro/projeto"
  ]
}
  • A última pasta aberta é restaurada automaticamente ao iniciar.
  • Até 10 pastas recentes no menu Arquivo.
  • Pastas inexistentes são removidas ao carregar a configuração.

Editor de código

Substitui o MultiLineEntry padrão do Fyne por um editor customizado com TextGrid, renderer próprio e camada de sugestões inline.

Paleta de sintaxe

Funções

Hello, Println

Structs / tipos

User, tipos declarados com type

Packages

main, paths e aliases em import

Keywords

func, type, struct, import

Strings

"texto", `raw`

Comentários

// e /* */

Rainbow brackets

Coloração de (), [] e {} por nível de aninhamento. Ignora conteúdo dentro de strings e comentários. Brackets sem par correspondente aparecem em vermelho.

Cursor e edição

  • Caret vertical piscante (2px), visível a cada 530 ms com foco.
  • Clique do mouse reposiciona o cursor na linha/coluna correta.
  • Pilha de undo com até 100 entradas (Ctrl+Z).
  • Formatação via goimports (Shift+Alt+F).

Integração gopls (LSP)

Cliente LSP via go.lsp.dev/protocol que inicia gopls serve por stdio e sincroniza documentos com didOpen / didChange.

Autocomplete

Lista inline

Painel de 6 linhas dentro do editor, sem roubar foco do teclado.

Filtro local

Digite para filtrar; reconsulta o gopls com debounce de 120–200 ms.

Snippets

Placeholders ${1:nome} e $0 expandidos ao aceitar.

Gatilhos

Ctrl+Space manual; ponto (.) após identificador; Enter/Tab para aceitar.

Navegação e análise

Recurso Descrição
Ir para definição Abre o arquivo e posiciona o cursor na declaração (stdlib e módulos).
Encontrar referências Lista todas as ocorrências; clique navega até ela.
Renomear símbolo Renomeia em todos os arquivos do workspace via WorkspaceEdit.
Diagnósticos Erros e avisos sublinhados em tempo real via PublishDiagnostics.
Signature help Ao digitar ( — balão com assinatura e parâmetro ativo.
Hover Mouse sobre identificador — documentação do gopls (debounce 400 ms).

Popups LSP convertem markdown para texto simples, quebram linhas em até 480 px e são posicionados abaixo da linha do cursor — evitando sobreposição ilegível sobre o código.

Terminal e execução

Painel de terminal PTY embutido na parte inferior do editor. A execução via F5 usa exec.Command diretamente, exibindo apenas a saída do programa.

Execução (F5)

  • Abre o terminal automaticamente se estiver fechado
  • Aguarda o shell ficar pronto antes de executar
  • Captura stdout/stderr sem ecoar o comando
  • Sem prompts > de heredoc na saída

Formatação

  • Shift+Alt+F — formata com goimports
  • Resolve binário via mesmo mecanismo do gopls
  • Menu Arquivo → Formatar documento

Realce de sintaxe Go

Parser de tokens com detecção de funções, tipos, packages e keywords.

Correção da execução no terminal

Tema Rainbow Brackets

Tema escuro One Dark Pro, editor TextGrid, formatação, execução e propriedades GOROOT.

  • theme.go, brackets.go, code_editor.go, format.go, run.go, settings.go

Como testar

go test ./...
go build -o go-ide .
./go-ide
  1. Abra um arquivo .go e verifique realce de sintaxe e rainbow brackets.
  2. Use Arquivo → Formatar documento (Shift+Alt+F).
  3. Pressione F5 para executar — o terminal abre e exibe só a saída.
  4. Abra uma pasta com código Go e teste autocomplete (fmt.).
  5. F12 ou Ctrl+clique para ir à definição; Shift+F12 para referências.
  6. Introduza um erro — sublinhado com mensagem ao passar o mouse.
  7. F2 para renomear; feche e reabra — a última pasta deve voltar.
